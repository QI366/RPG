# 《雾港来信》美术提示词

先生成三张人物立绘。风格统一后再补背景。你把图片发回来即可；也可以按下面文件名放入 `assets/art/`，刷新页面自动替换人物占位。当前代码已支持 PNG 立绘；无需修改组件。

## 统一约束

- 竖图 2:3，建议 1024×1536，单人，膝上或全身，人物居中偏右，头顶留 8% 空间。
- 优先透明背景 PNG；生成器不支持透明时，用单一深灰绿背景，避免复杂场景。
- 三人使用同一画风、相同镜头距离和柔和侧光，保留衣服轮廓、完整双手。
- 页面底部会覆盖角色姓名，不要把关键道具放在最下方 20%；名字由网页排版，图中不要文字。
- 以下均为原创成年角色。先用林汐确立风格，再把成图作为另两人的风格参考。
