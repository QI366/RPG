# 雾港来信 · Fog Harbor

> 当记忆也会说谎，你选择相信谁？

一个可本地运行的 AI 叙事 RPG 作品集项目。玩家在记忆被交易的海港城市调查父亲失踪，通过证据收集、人物交谈和最终选择抵达不同结局。第一章包含 **3 位人物、5 个地点、14 个剧情节点、7 条可收集线索、4 个结局**，约 10–15 分钟。

## 快速开始

需要 Node.js 22.9+。项目使用 Node 原生 HTTP、浏览器 ES Modules 和原生测试框架，无需安装依赖。

```powershell
npm start
```

打开 <http://127.0.0.1:3000>。默认是**本地检索模式**：根据已解锁线索生成规则回复，界面会明确标注。剧情、调查、存档与结局都可以离线体验（首次启动仍需本地服务）。

### 启用模型对话

```powershell
Copy-Item .env.example .env
# 在本地编辑 .env 的 AI_API_KEY、AI_API_BASE、AI_MODEL、AI_WIRE_API
npm start
```

服务支持 Chat Completions（`AI_WIRE_API=chat`）和 Responses（`AI_WIRE_API=responses`），均校验 JSON 输出。Responses 请求不带 Chat 专用参数，使用 `store=false`，从 assistant 消息提取文本并检查完成状态；可用 `AI_REASONING_EFFORT` 指定供应商支持的推理档位。不同供应商兼容性可能不同；服务端遇到超时、HTTP 错误或非法输出会降级到本地检索，并在本条回复的“对话依据”中说明原因。模型模式下，问题、最近 6 条消息和检索出的剧情片段会发送到配置的模型服务。

### 复用 CC Switch 的 Codex 配置

本机 `.env` 已导入 CC Switch 当前选中的 Codex 供应商配置，使用 Responses、`gpt-5.6-sol`、`high` 推理档位与 60 秒时限。配置为本地快照：之后在 CC Switch 切换供应商或模型，不会自动修改本项目。

对应关系：`base_url` → `AI_API_BASE`、`model` → `AI_MODEL`、`wire_api` → `AI_WIRE_API`、`model_reasoning_effort` → `AI_REASONING_EFFORT`；Bearer Token / API Key 仅写入本地 `AI_API_KEY`。保留供应商原始 base URL，不擅自补 `/v1`；项目会追加 `/responses` 或 `/chat/completions`。修改后重启服务生效。

前端根据服务端时限调整等待时间；每条模型回复的“本次对话依据”会展示实际模型和耗时。`AI 模型已配置` 仅说明服务端有配置，实际是否调用成功以回复来源为准。

`.env` 已忽略，密钥只由服务端读取。无需把密钥填进网页。默认仅监听本机；本项目是单机作品集原型，部署到公网前应补齐身份认证、用户隔离、持久化与费用配额。

## 可以演示什么

- **内容驱动剧情**：条件和效果白名单、不可变状态更新、两条调查顺序、关键证据共同解锁公开结局。
- **有依据的人物对话**：人物设定 + 当前剧情状态 + 角色可见线索 + 有限对话记忆，按关键词加权检索 Top-3。
- **可检查的 AI 输出**：JSON 结构校验、引用 ID 白名单、未知标记、耗时、实际回复来源；AI 不执行剧情操作。
- **可靠回退**：未配置密钥、供应商报错、超时、返回非 JSON 或引用未检索证据时，转入本地规则回复。
- **可恢复进度**：自动/手动保存、JSON 导入导出、版本校验与历史重放、跨周目结局收藏。
- **完整视觉演示**：桌面三栏与移动端布局、手记与足迹、人物切换、程序绘制的港口与占位立绘；支持直接替换 PNG。

## 验证

```powershell
npm test
npm run validate
npm run eval
```

18 项测试覆盖规则、存档、检索边界、两种协议的模型接口 mock、错误回退、HTTP 请求限制和私有文件隔离。内容校验遍历 **80 个有效状态**，检查死路与全部结局可达性。6 条本地评测覆盖检索与状态隔离；**这些结果不代表真实模型的准确率、抗注入成功率或线上负载能力**。

## 当前边界

这是**剧情图 + 检索增强人物对话**，当前检索是透明可解释的关键词加权方案，没有使用向量数据库、模型微调或多智能体调度。剧情与结局由规则引擎负责，模型补充人物表达。信任值参与提示词和 UI 展示，不作为生成事实的依据。

引用校验能阻止未知引用进入展示，无法证明生成语句与引用语义一致；提示词也无法彻底消除模型编造。客户端持有完整剧情，历史重放用来维护状态一致性，不是防作弊系统。存档不包含对话文本，对话仅在当前页面会话保留，刷新后清空。
